# Elevenpoint releases

This repo holds the installers for Elevenpoint, a desktop app that checks websites for broken links, accessibility problems, SEO issues and invalid HTML.

The easiest way to get it is the [download page](https://elevenpoint.app/download/), which picks the right file for your computer. Or grab one from the [latest release](https://github.com/portseif/elevenpoint-releases/releases/latest):

- Mac with Apple silicon (M1 or later): the `-arm64.dmg`
- Mac with an Intel processor: the `-x64.dmg`
- Windows: the `-setup.exe`
- Linux: the `.AppImage` or the `.deb`

Not sure which Mac you have? About This Mac lists a Chip for Apple silicon or a Processor for Intel.

Once it's installed, Elevenpoint looks here for new versions and updates itself. You can switch that off in Settings › Updates.

The source code is in a private repo. This one only has the builds.
