# Elevenpoint releases

This repo holds the installers for Elevenpoint, a desktop app that checks websites for broken links, accessibility problems, SEO issues and invalid HTML.

Grab the latest version from [Releases](https://github.com/portseif/elevenpoint-releases/releases/latest). Mac users want the `.dmg`, Windows users the `-setup.exe`.

Once it's installed, Elevenpoint looks here for new versions and updates itself. You can switch that off in Settings › Updates.

The source code is in a private repo. This one only has the builds.
